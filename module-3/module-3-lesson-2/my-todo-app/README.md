## Container and Presentational Components

In this task we've used a container and presentational component pattern. We achieve this by having our main To Dos in the `App` component and then passing the data down to the `ToDoList` component. This is a common pattern in React and is used to separate concerns and make our code more readable and maintainable.

### Mixed use of a normal `function` and arrow functions

In this task we've used both the normal `function` keyword as well as arrow functions. This is so you can see how to handle both types of functions in the same codebase. In the real world, you'll want to be consistent and only use one or the other.
